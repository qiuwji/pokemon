# 未白镇 BGM 包

曲目：MUS_LITTLEROOT。先打开 preview.html 或 mus_littleroot.wav 试听。

在项目根执行 `python3 emerald-littleroot-bgm/install.py --check` 预演；去掉 --check 安装。
刷新游戏，以 `?plugins=emerald-first-bgm` 启用试听插件，走到未白镇并点击 ♪ 开启声音。
插件默认关闭，不改变规则/存档；安装仅绑定当前同原曲的地图并复制音频/登记插件。
原作数据重新导入覆盖 music 后，可再次运行安装命令。

音乐包含引子和两遍循环，游戏循环第二遍以保留已建立的尾音。普通播放器会在文件末尾停止。
这是源资料离线渲染试听版，用户已确认游戏中能听到音乐；持续循环听音、原作对照及硬件逐位保真尚未验收。
完整战斗/剧情选曲和短曲恢复不在本单曲包范围。

复生成器、固定依赖与命令见项目 tools/audio/README.md；循环、哈希和来源见 manifest.json。
