# 跟随伙伴

用一位普通少年来验证通用 Actor 能力。插件入口默认启用，不自动生成角色、发奖励或改变原作剧情；宝可梦队伍绑定与素材仍留后续。

## 怎么玩

主菜单 → 跟随伙伴 → 叫来伙伴。关闭菜单后走路，他会沿你已走完的路线跟来；转弯时保留路线，停下时站在相邻格。挡路会等候，菜单/对话/战斗沿宿主规则暂停。页面可原地等候、继续跟随或告别，并查看最近 8 条动作。

身边须有合法陆地空格。重复叫来保留同一身份；跨相邻道路正常走连接，进门/传送到另一地图在合法邻格重新加入。当前场景忙碌或邻格被占时等下一个动作边界重试，也可手动点“叫回身边”。等候中的伙伴不会跨门自动跟来。此例未验证冲浪、骑车、跳崖、离屏模拟或特殊交通。

可在插件管理器开关“跟随伙伴”，或用 `?plugins=patrol-lab` / `?disable-plugins=patrol-lab`。保留原实验模块 ID，不需要修改应用接线。

## 边界与保存

插件拥有一份行为、模板、控制动作、只读 report 和菜单页面；仅声明 actors 权限。沿公开 core:motion 收集玩家非脚本落步来源，路线最多 32 格，观察最多 24 条。溢出清理后用既有目标寻路靠近玩家；不在引擎保存跟随历史或建立跟随关系。

移动、预约、碰撞、动画、宿主暂停和权威位置由引擎/Actor 仓储负责。插件只保存成员 UID，等候标志在 schema 化 Actor 记忆中；创建 UID 与插件记录在同一事务提交，失败回滚。路线和观察缓冲不序列化。停用后相关 Actor 暂停保管，正常游戏可继续；重新启用恢复身份和位置，不重复创建。

运行 `node --test examples/patrol-lab.test.js`。使用真实宿主与模拟时钟/UI/存储，未操作浏览器；键盘/触屏、画面和听感待用户确认。最终证据见[manifest](../../../docs/validation/2026-10-07-follow-and-contracts/manifest.json)。
