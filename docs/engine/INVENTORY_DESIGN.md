# 原作槽位库存设计与实施记录

状态：2026-10-03，核心、应用消费者/生产者、选槽页面、插件事务和保存10迁移已完成并针对性验证。现行合同与证据见[INVENTORY.md](INVENTORY.md)。下表保留设计动机及边界，不再作为未实现计划。

## 实施目标与权威状态

已建立可复用 InventoryRegistry / InventoryService；应用层已接入该唯一服务，规则包注入口袋定义，内容物品声明 pocket。采用唯一持久槽位状态，保留原作顺序、空位、分散同物品堆叠和所选槽位移除语义。禁止同时持久化“槽位”和另一份可写数量字典，防止两份真相。

上层的 bag 数量查询继续是派生只读投影；消费者通过领域 quantity/prepare/commit/preview 等有限端口使用库存，而不是直接写投影。这是新合同的查询层，不增加旧存档读入或旧字段赋值兼容。保存schema、生产调用点和受影响夹具已统一更新。

现行槽位数据：`bag:{pockets:{pocketId:[null | {item,count}]}}`。口袋按注册容量分配稳定位置，空位为 null；全空口袋可省略并在只读视图投影。库存条目至少包含物品引用和正整数数量；唯一/重复规则、堆叠限制和口袋容量由注册定义决定。完整schema及命令以INVENTORY.md和当前实现为准。

## 已确认的第三世代规则

固定只读参考 revision 731ad5bfd6e6f265508d0efcca0ba42f9dcf5881：

- include/constants/global.h：普通30槽、重要道具30槽、精灵球16槽、TM/HM64槽、树果46槽。
- include/constants/items.h：普通堆叠99，树果999；PC存物999为另一个容器合同，不能混入普通背包。
- src/item.c CheckBagHasSpace/AddBagItem：先填已有堆叠，再分配空位；普通/球/重要道具可有重复堆叠，TM/HM与树果不能创建同物品第二槽。数量或空位不足时整个追加失败，不留下部分填充。
- src/item.c RemoveBagItem：优先所选匹配槽，再按顺序移除剩余量；数量为零清空。不能用总数量向上取整模拟真实槽位，移除/整理后会存在分散堆叠。

口袋名称、容量、堆叠上限和重复政策属于可注册数据，通用服务不得写死上述数字。插件添加口袋/物品时需启动期引用校验、只读容量视图、同一受控操作和保存依赖。

原作 Pokéblock case、战斗金字塔背包、PC 存物具有独立容量/数据与使用规则，应在设施/养成领域复用容器原语并定义自身政策；不能静默当普通背包。本项目 blue_pokeblock 为静态演示物品，完整个体能量方块制作/保存仍待 D。

## 已迁移的真实读写边界

| 生产调用点 | 已实施的库存领域合同 |
| --- | --- |
| InventoryApplication 商店 buyItem | 先预检数量/容量/金钱，同批提交库存和扣款；拒绝时都不变 |
| engine/story grantReward、StoryApplication、插件 reward intent | 预检整个物品组合，再提交金钱/旗标/库存/奖励 ledger；满包不得标记已领取。剧情/插件共用领域，不复制规则 |
| EquipmentService | 以UID确认对象，给予与返还旧持物作为同一库存变化；返还无空间则伙伴/库存都不变 |
| CropApplication | 采摘前检查整份产量的容量，再清树和提交库存；不能先清树再失败 |
| ItemService / MoveLearningService / EvolutionService | 通过库存操作支付费用；保留现有目标草稿、四槽/受保护招式、过期/一次计划保护；同批变更明确责任 |
| BattleControllers / roster / items | 每个控制者持有自己的库存视图/容器；行动预留和消耗沿用同一数量端口，不能只迁移玩家战斗 |
| FieldActionApplication / ItemShortcutApplication | 从领域查询数量；规则回调仍收到冻结的数量投影，字段不提供写入入口；登记原生命周期保持 |
| Save / 插件事务快照 / 注册依赖 | 只保存槽位真相；拒绝坏口袋/堆叠/引用，回滚与读档重绑后访问实时容器，不留旧引用 |
| bag/shop/party/growth UI 与调试查询 | 页面只提交现有应用命令；通过投影显示，不再读写持久数量字典。选中槽位需稳定引用与执行时核对 |

剧情旧grant与legacy.*奖励ID已删除，当前业务/夹具使用唯一reward；参考目录保持只读。
