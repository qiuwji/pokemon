# 宝可梦中心治疗演出

来源固定为 `731ad5bfd6e6f265508d0efcca0ba42f9dcf5881`：`data/scripts/pkmn_center_nurse.inc`、`src/field_effect.c`、`src/sound.c`、护士动画与图片索引表。普通护士入口保持欢迎、是/否、接收、面左、治疗、面下、返还、鞠躬和告别；拒绝不回血。金卡、宝可病毒与联机提醒分支尚未转写。

治疗球使用原作8×8索引图及调色板，屏幕使用24×16两帧；原坐标(93,36)/(124,24)，球位偏移(0/6,0/4/8)。队伍计数含蛋，球以25帧间隔出现，最后一球后32帧播放MUS_HEAL。闪烁改变调色板的指定颜色组，红/绿系数16、12、8、0，蓝色不变；三轮8帧分组闪烁后统一闪烁、30帧保持并移除，监视器16帧交替共128帧。短曲期间地图BGM暂停，160帧等待后从原采样位置继续。GBA任务和精灵回调的先后相位仍需实机逐帧对照。

编排在内容包，帧编译、有限时钟、精灵绘制与音频暂停租约各自独立。UI不再手绘治疗球或持有这段演出的定时器。护士鞠躬采用原图帧3（C动画索引9通过sPicTable_Nurse映射到图片3），不是旋转、位移或自造图。治疗失败释放剧情控制，队伍不提前恢复，可以再次交互。

另修复野生战入场结束后文本停留再次播放入场：文本事件仍携带introPhase，旧采样器未检查事件kind；现在仅entry/trainer-slide可以调用入场取样。

用户追加截图中的绿色遮盖来自`:has(.menu-grid)`背景规则覆盖了field透明规则，现修正field叠层选择器；是/否框保留三角游标，移除多余焦点矩形并整理行距。实际布局待用户复看。

资源复生成：`python3 tools/field/export-center.py`；只读检查加`--check`。短曲配置在`tools/audio/tracks/mus-heal.json`，按[音频流程](../../tools/audio/README.md)渲染与合包。[证据](../validation/2026-10-08-center-and-entry-fix/manifest.json)记录实际验证。没有操作游戏；实际坐标、渲染遮挡、听感及回调逐帧相位待用户验收，不能把模块测试称为全场景1:1验收。
