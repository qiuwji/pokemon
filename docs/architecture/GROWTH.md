# 育成领域与可玩流程

育成逻辑是浏览器无关的服务，不依赖研究所界面或动画。`GrowthSession` 装配亲密度、培育、孵化和进化；领域提交返回事实，`GrowthDirector` 在白色遮盖时提交，再展示结果。输入与 NPC 在演出期间暂停，失败释放锁。

## 服务与扩展位置

| 服务 | 职责 | 扩展方式 |
| --- | --- | --- |
| BreedingService | 配对、生育概率、后代与遗传 | 物种蛋组、蛋招式、机器招式、后代/香炉定义与继承策略 |
| DaycareService | 寄存、步数、产蛋、收费、领取 | 注入培育服务；寄存期保存原招式，领回时结算经验与招式 |
| HatchService | 蛋时钟与孵化提交 | PartyTraits 的 hatch-rate 阶段；不改个体 UID |
| FriendshipService | 亲密度变化与步数 | friendship-modifier 同一规则管线 |
| EvolutionService | 校验条件、生成计划、一次提交 | GrowthConditions 注册条件；进化规则描述触发器和组合条件 |
| TradeService | 双方队伍交换身份与所有权标记 | 本地队伍接口，与传输及动画分离 |
| NutritionService | 口味、美丽度等与饱食度 | 道具效果表的 feed 操作，食物参数描述增量 |
| PartyStorageService | 入盒、领回与交换 | UID 保持，双方保留能战斗的成员 |
| StateCheckpoint | 身份保持的会话回滚 | 捕获 JSON 状态对象图和随机数，不捕获运行时服务 |

进化按物种 ID 注册数组，规则包含唯一 id、to、trigger（level/item/trade）和 conditions。条件支持等级、亲密度、美丽度、时间、持有物、进化石、能力比较及个体性格。可注入新谓词；拼错条件、循环谱系、未知目标与道具在启动时失败。计划由服务签发，校验个体、队伍及库存指纹，伪造、过期和重复提交不会消耗道具。

交换与其后进化作为一个应用操作，发生失败会恢复双方对象身份、招式、库存和 RNG。道具同样先计算副本，再确认目标和库存未变化后提交。UI 不直接改育成或库存状态。

## 绿宝石规则覆盖

| 规则 | 实现与边界 |
| --- | --- |
| 配对 | 蛋组、性别、百变怪、不能生育组、同种与原训练家影响 20/50/70 概率 |
| 产蛋时钟 | 第二寄存栏步数低八位达到 255 时检查；等待领取期间不重复生成 |
| 寄存经验 | 原始个体保持寄存时等级/招式，领回结算步数经验，费用 100 ×（增加等级 + 1） |
| 后代 | 进化谱系回溯、香炉、特殊后代定义；母方或非百变怪方决定谱系 |
| IV/性格/招式 | 绿宝石三次 IV 继承包含原作重复位置现象；不变石性格继承；父方蛋招式、机器招式、双方等级招式 |
| 孵化 | 八位时钟 255 边界、蛋周期、火焰之躯/熔岩铠甲缩短、同一时刻优先一颗蛋；孵化 UID 保持、亲密度 120 |
| 普通进化 | 等级、进化石、亲密度、白昼/夜晚与交换 |
| 分支进化 | 无畏小子能力比较、刺尾虫 PID 分支、伊布、珍珠贝持有物交换、丑丑鱼美丽度 |
| 土居忍士 | 铁面忍者 + 空位生成脱壳忍者（HP=1，无性别）。绿宝石没有额外精灵球消耗；额外成本可由其他规则包描述 |
| 道具/特性联动 | 不变石、安抚之铃、熔岩铠甲/火焰之躯、香炉、交换进化持有物进入现有阶段或领域条件 |
| 蛋的边界 | 可随队、寄存盒子和交换；不能出战、治疗或装备；不能在培育屋再次寄存 |

当前内容包含 58 种精灵、87 个招式、29 个谱系的 37 条进化描述。未导入招式保存在 unavailableLearnset，而不会创建未知招式。引擎支持扩展谱系；这不代表已导入全部物种和机器招式。

PRNG 保持可复现，采用项目随机数算法，不承诺 GBA 位级随机序列。继承性格后 PID、性别和特性保持一致。时间条件沿绿宝石规则（12–24 为 day，0–12 为 night），昼夜画面和原作保真程度另看表现规格/STATUS。

研究所的育成研究与研究员交换是当前地图切片的可玩验证入口，并非声称已完成 117 号道路培育屋剧情。蓝色能量方块是美丽度进化验证食物；选美及能量方块制作小游戏未加入。

## 历史实测与检查（v0.9.0）

浏览器完成：寄存两位伙伴、领取蛋、行走孵化、土居忍士进化并出现脱壳忍者、进化后招式选择、与研究员交换勇基拉并进化为胡地。存档保存蛋时钟、寄存步数、交换伙伴和唯一个体身份；此阶段开发档版本为5；这是历史观察，当前版本见README，旧开发版本不兼容。

完整自动检查 263 项。育成检查覆盖所有当前进化分支、蛋资格、性格/PID、步数/概率、道具消费、学习联动、营养饱食、失败回滚、一次提交、演出锁与存档身份。
