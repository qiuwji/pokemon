# 原作NPC与地图交互补齐

来源固定为pret/pokeemerald修订731ad5bfd6e6f265508d0efcca0ba42f9dcf5881；[逐区清单](NATIVE_NPC_INVENTORY.json)记录67张已导入地图、446个来源槽位，包括隐藏对象。导入地图/普通对白不等于完整剧情和设施。仍待转写对象保留pending，后续按地区继续。

## 本批实现

- 转写106段普通对白，实际入口覆盖90个可见对象；17个卡那兹/武斗条件或命名宝可梦互动，保持源码判断顺序和小孩转回原朝向。HM居合斩、先机球、先制之爪三项赠礼支持背包满后重试及读档去重，学校老师按左右接近方向走原作检查路径并回位。
- 路牌及室内展品68段脚本、117处来源入口；映射5个遗漏道具球。104西侧少年无对白来自不存在的tm09物品引用，现使用tm_bullet_seed，并在装配时拒绝错误赠品引用。
- 五处精灵中心和四处商店通过真实柜台交互：护士确认/取消，恢复HP、状态、PP；商店读取独立pack库存表、保留购买事务/金额/容量约束。卡那兹特殊球库存依据116道路的独立会面标志，不冒用森林救援标志。
- 花店三位店员接原作早期问答、喷壶和每日八类树果赠礼；礼物失败不占用完成标记。花店来源高度绑定地形，玩家与NPC双方移动均遵守占位。得文3F隐形桌前代理保持碰撞及交互，表现不再画出第二个社长；来源隐形查询放在pack绑定层。
- 102/103/104/116道路共19处原作树果土壤。空地保留空，采摘不复生。旧104总标记迁移至逐株初始化标记并消费旧flag，应用层不再判断地图。贴图导出修正原作横排帧布局，逐像素校验27张生长图；旧PNG透明是刷新后仍看不到树果的根因。
- 水舰队/火岩队十种训练家身份选择各自原作入场图案，正弦编织、停留和圆形闭合采用来源阶段时长；总217帧。Canvas混合色不是GBA逐像素相加色彩的完整复现，尚需实玩视觉验收。

## 本次刷新存档兼容修复

第一版凰梨果定义曾用180分钟、2–3产量；对齐原作改成60分钟、3–6产量后，已初始化的旧树会被严格校验拒绝，当前位置即使在卡那兹也会触发。pack存档投影在最终校验前只迁移符合旧定义、却不符合当前定义的原生树记录：按比例转换剩余时间，成熟产量至少3。保留阶段、浇水、循环、已采摘状态与其他进度；当前合法记录不改。坏记录及无关损坏仍拒绝，成功投影保留原始存档备份，不降低引擎校验。
